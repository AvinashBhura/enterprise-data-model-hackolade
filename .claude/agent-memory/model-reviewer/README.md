# Memory for the `model-reviewer` agent

The agent may keep short notes here between sessions, one topic per file.

**Keep:** conventions learned in this repository that are not written down
elsewhere, recurring review findings and their usual fix, and pointers to the
files that answered a question.

**Never keep:** secrets, licence keys or credentials; personal data about
anyone; content of model files (read the model instead); and anything that is a
decision. Decisions belong in `docs/decisions/`, rules in
`config/edm-rules.yaml`, and requirements in a spec.

Notes here are hints, not authority: when a note and the repository disagree,
the repository wins, and the note is corrected or deleted.
